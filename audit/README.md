# Audit Workspace

This directory is generated and maintained by the Claude audit workflow.

## Status

Initial status: not started.

## Suggested sequence

1. `/audit`
2. `/bug-hunt`
3. `/api-audit`
4. `/security-audit`
5. `/ui-audit`
6. `/dependency-audit`
7. Review findings
8. `/fix` for selected findings
9. `/regression`
10. `/final-report`

Do not treat the final report as evidence of testing that was not actually performed.
